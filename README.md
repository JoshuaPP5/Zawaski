# 🃏 Zawaski: The Infinity Tower

[![Java Version](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)](https://www.oracle.com/java/)
[![Game Genre](https://img.shields.io/badge/Genre-Strategic%20CCG-blueviolet?style=for-the-badge)](https://github.com/)

> **"Will you conquer the tower, or will you become one of its forgotten souls?"**

**Zawaski** is a strategic card-collecting game (CCG) developed in Java. Players find themselves trapped in the mysterious **Infinity Tower**, an ever-changing labyrinth filled with ancient guardians and arcane traps. To escape, you must harness the power of magical cards drawn from forgotten realms, forging powerful decks to overcome the tower’s many dangers.

---

## 🏰 Game World & Lore
The Infinity Tower is not just a building; it is a living entity. As a player, your survival depends on your ability to manage your **Action Points (AP)** and build a deck capable of defeating the guardians of each floor. Every step higher brings greater rewards—and deadlier threats.

## 🚀 Key Features

### ⚔️ Battle System
* **Turn-Based Strategy:** Tactical combat where every move counts.
* **Resource Management:** Receive random action cards and a fixed set of **AP** each turn.
* **Progressive Difficulty:** Defeat enemies to ascend to higher floors with scaling difficulty.

### 🏪 Shop & Economy
* **Fixed Market:** Buy specific cards to round out your strategy.
* **Gacha System:** Test your luck to pull rare, high-tier cards from randomized draws.
* **Trading:** Sell unwanted cards to refine your deck and gain resources.

### 👤 Player Management
* **Account Security:** Full Login/Register system with **file-based storage** and **encrypted passwords**.
* **Multi-Character Support:** Create and manage up to 3 unique characters per account.
* **Profile Tracking:** Real-time character stats, health, and ability tracking.

### 🏆 Social & Competitive
* **Global Leaderboard:** Rank against other players based on high scores.
* **Pagination:** Smooth navigation through large lists of competitive players.

---

## 🛠️ Technical Stack
* **Language:** Java
* **Data Persistence:** File-based storage (for User & Character data)
* **Security:** Password encryption/hashing implementation
* **Design Pattern:** MVC, Singleton, SOLID Principle

---

## Prerequisites
- Java JDK 17 or higher
- Eclipse IDE (Recommended)

## Running the Game
To run the game directly from your terminal using the compiled files:

**1. Navigate to the bin folder:**
```
cd Zawaski/bin
```

**2. Run the application:**
```
java zawaski/Main
```
